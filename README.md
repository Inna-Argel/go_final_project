# Планировщик задач

Веб-сервер для управления задачами (TODO-лист) с поддержкой повторяющихся событий.

## Задания со звёздочкой

Не выполнялись.

## Запуск локально

1. Установите зависимости:
   go mod download

2. Запустите сервер:
   cd cmd && go run main.go

3. Откройте в браузере:
   http://localhost:7540

## Запуск тестов

go test ./tests

## Переменные окружения

- TODO_PORT — порт сервера (по умолчанию 7540)
- TODO_DBFILE — путь к файлу БД (по умолчанию scheduler.db)
- TODO_PASSWORD — пароль для аутентификации
